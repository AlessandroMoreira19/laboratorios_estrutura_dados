Este repositório foi criado para armazenar os projetos, laboratórios e exercícios práticos desenvolvidos durante a disciplina de **Estrutura de Dados**, utilizando a linguagem **C**.

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** C (Padrão C11 ou superior)
* **Compilador Recomendado:** GCC / Clang
* **Ambiente de Desenvolvimento:** VS Code / Terminal

---

## 🚀 Como Executar os Projetos

Para clonar e compilar qualquer um dos projetos localmente, siga os passos abaixo no terminal:

### 1. Clonar o repositório
```bash
git clone https://github.com
cd laboratorios_estrutura_dados
```

### 2. Compilar um arquivo (Exemplo)
Navegue até a pasta do laboratório desejado e compile o arquivo principal:
```bash
cd "Biblioteca Matemática"
gcc main.c -o programa
```

### 3. Executar o programa
* **No Linux/macOS:**
  ```bash
  ./programa
  ```
* **No Windows:**
  ```bash
  programa.exe
  ```
